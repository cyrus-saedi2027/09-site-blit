# هیرو · نسخه‌ها · Hero versions

همه‌ی نسخه‌های هیرو اینجا کنار هم هستن. `index.html` همین پوشه صفحه‌ی مقایسه‌ست: هر نسخه کل پنجره رو می‌گیره و دقیقاً همون‌طور که هست باز می‌شه (نوار بالا نداره). برای جابه‌جایی، دکمه‌ی گرد تنظیمات پایین‌چپ رو بزن و تو پنلش «مقایسه‌ی نسخه‌ها» رو انتخاب کن (یا کلیدهای ۱ تا ۹)؛ «اندازه‌ی نمایش» هم همونجاست (مثلاً ۱۹۲۰×۱۰۸۰ دقیق، حتی تو پنجره‌ی کوچک).

Every hero version, side by side. `index.html` in this folder is the comparison page: **no bar at all**, the chosen version fills the whole window at its real size. To move between versions open the round settings button (bottom-left); the panel has a «مقایسه‌ی نسخه‌ها» group (or press keys 1–9, or use `#v1` … `#v9` in the URL; `#v9@1920x1080` also fixes the preview size). Versions 6, 7, 8 and 9 carry that group (and an «اندازه‌ی نمایش» group: the page in a frame of exactly 1920×1080, 1440×900 … scaled to fit) in their own panel (it talks to the page through `postMessage`); versions 1–5 have no panel, so the page shows a tiny floating capsule for them instead.

Wide windows keep the composition centred; tall ones and phones stack the panels. The comparison page can show any version in a frame of exactly 1920×1080 (or 1440×900 …), scaled to fit. Uses the same four real banners (the files aren't in git) | new, waiting for feedback |

Each version has its own `SPEC.md` handoff and assets. The songs are shared in `assets/music/` and aren't committed (see the README there). Versions 8 and 9 real banners aren't committed either (`v8/assets/events/README.md`, `v9/assets/events/README.md`).

```bash
cd ui-reference && npx http-server -p 8000
# open http://localhost:8000/01-hero/         (the comparison page)
# or   http://localhost:8000/01-hero/v9/      (one version on its own)
```
Version 1 needs WebGL for its stage; without it, it shows a CSS fallback.
