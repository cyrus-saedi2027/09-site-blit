# پوسترها و بنرهای نمونه · Sample posters and banners

این فایل‌ها تو گیت نیستن. پوستر و بنر واقعی کار برگزارکننده‌ها و هنرمندهاست و این مخزن عمومیه. نسخه‌ی خصوصی پیش‌نمایش خودش فایل‌ها رو داره.

These files are **not committed** (real organisers' artwork, public repository). Without them version 8 still runs: when a file is missing the page draws a stand-in banner or poster from the show's title and colour, so the layouts can still be judged.

## اجرا روی سیستم خودت · Running locally with the real art

Put the files here with exactly these names (`-banner-*` is 16:9, `-poster-*` is a tall poster):

| Show | Banner | Poster |
|---|---|---|
| SkyKings (concert) | `skykings-banner-1672.webp` · `-1024.webp` · `-640.webp` | `skykings-poster-800.webp` · `-400.webp` |
| زندگی شاید… | `zendegi-shayad-banner-…` | `zendegi-shayad-poster-…` |
| دو دقیقه به هشت | `do-daghighe-banner-…` | `do-daghighe-poster-…` |
| دختر بودن یا پسر نبودن | `dokhtar-pesar-banner-…` | `dokhtar-pesar-poster-…` |

Sizes: banners 1672×941 (sources) plus 1024 and 640 wide copies; posters 800 wide plus a 400 wide copy. All WebP, 80–90 quality.
