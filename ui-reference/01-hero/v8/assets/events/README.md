# بنرهای نمونه · Sample banners

این فایل‌ها تو گیت نیستن. بنرها کار برگزارکننده‌ها و هنرمندهاست و این مخزن عمومیه. نسخه‌ی خصوصی پیش‌نمایش خودش فایل‌ها رو داره.

These files are **not committed** (the banners are other people's artwork: organisers, artists, a ticketing site's logos; this repository is public). Without them version 8 still runs: when a file is missing the page draws a stand-in banner from the show's title and colour, so the layouts can still be judged.

Only banners are used here. The hero's background is always a wide 16:9 banner; tall posters belong to other sections (the poster shelf) and the admin panel refuses them.
