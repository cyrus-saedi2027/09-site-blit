# tools/halls · داده‌ی سالن‌ها و شهرها

این پوشه خودِ بسته‌ی سالن‌ها را **ندارد** (ریپو عمومیه؛ بسته، PNGها و عکس‌های مرجعش کامیت نمی‌شن). فقط ابزاری هست که داده‌ی صفحه را از روی بسته می‌سازد.

- `build_halls.py <پوشه‌ی بسته> <cities-source.json> <پوشه‌ی خروجی>` ← `halls-data.js` (همان `GEO_DATA`، `HALLS_DATA`، `HALL_ALIAS`، `PLANS_JSON` که `01-hero/v9/index.html` داخل خودش دارد) و `halls-report.txt`. هر چیدمان رمزگذاری می‌شود و همان‌جا دوباره رمزگشایی و با بسته مقایسه؛ اگه یک خانه فرق کند ساخت متوقف می‌شود. قواعد صاحب پروژه (بدون مختصات = بدون موقعیت، ظرفیت بدون «خارج از ظرفیت»، چند چیدمان برای یک سالن، یادداشت‌ها و شماره‌ی نمادین) اول فایل نوشته شده.
- `make_cities_source.py` ← `../../data/cities-source.json`: فهرست **موقت** ۳۱ استان و ۴۸۲ شهرستان (از ویکی‌پدیای فارسی؛ کلید هر شهر همان اسم انگلیسی ویکی‌پدیاست، مثل کلیدهای خود بسته) و ۵ شهر اضافه. وقتی صاحب پروژه فهرست ۴۸۵تایی خودش را فرستاد، با همین قالب جایش بگذار یا از «افزودن گروهی» در پنل مدیر (`#/admin/cities`) بریز.
- خروجی را تو `parts` صفحه (`halls-data.js`) بگذار و صفحه را دوباره بساز. بعد `integrity-test.js` را اجرا کن.

اجرا: `python3 -I build_halls.py <بسته> ../../data/cities-source.json <خروجی>` (پوشه‌ی بسته را فقط می‌خواند).
